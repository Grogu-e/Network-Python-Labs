Network Python Labs
A collection of hands-on Python networking and cybersecurity labs developing using Parrot OS. 
LAB 01: TCP Client
Objective
Build a TCP client using Python socket module to understand network communication and HTTP requests.

Technologies:
Parrot OS
Python
TCP/IP
HTTP/1.1
Virtual Box

Lessons Learned:
Creating TCP sockets with Python
Understanding localhost
Sending HTTP GET requests
Encoding and decoding network data
Receiving server responses
Troubleshooting Python syntax,indentation, and connection errors.

LAB ENVIRONMENT:
ALL networking experiments are performed in an authorized local environment.
